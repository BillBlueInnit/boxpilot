# BoxPilot 使用说明

[English](usage.md) · **简体中文** · [Русский](usage.ru.md) · [返回 README](../README.zh-CN.md)

本说明带你从安装 BoxPilot 开始，一直到按自己的想法让各个应用经由节点上网。

## 1. 安装

从 [Releases](https://github.com/BillBlueInnit/boxpilot/releases) 下载对应系统的文件。

| 系统 | 文件 | 方法 |
| --- | --- | --- |
| Windows 10/11 | `BoxPilot-<版本>-windows-x64.zip` | 解压到任意位置，运行 `boxpilot.exe`。 |
| macOS，Apple 芯片 | `BoxPilot-<版本>-macos-arm64.dmg` | 打开 .dmg，把 **BoxPilot** 拖到 **Applications（应用程序）**。 |
| macOS，Intel | `BoxPilot-<版本>-macos-x64.dmg` | 同上。 |
| Linux x64 | `BoxPilot-<版本>-linux-x64.tar.gz` | 解压后运行 `./boxpilot`。 |

**macOS 首次打开。** BoxPilot 没有经过 Apple 公证，第一次打开时 macOS 会询问。在“应用程序”中右键点击
BoxPilot → **打开** → **打开**。macOS 15 及更新版本：先打开一次，然后前往**系统设置 → 隐私与安全性**，
点击**仍要打开**。如果提示应用“已损坏”，在终端运行一次下面的命令后再打开：

```bash
xattr -dr com.apple.quarantine /Applications/BoxPilot.app
```

**Linux。** 托盘图标需要支持 AppIndicator 的托盘（GNOME 需安装 AppIndicator 扩展）。

BoxPilot 会自行更新：在**设置 → 更新**中选择新版本是自动安装、仅提醒还是从不通知。

## 2. 获取 sing-box 内核

BoxPilot 驱动 [sing-box](https://sing-box.sagernet.org) 内核，但不附带它。在**仪表盘**点击**下载内核**
（或**设置 → sing-box 内核 → 下载最新版**），BoxPilot 会从 GitHub 下载适合你系统的官方版本。如果
GitHub 访问较慢，可先在同一栏设置 **GitHub 镜像**前缀。

## 3. 添加节点

### 服务商提供的订阅

**订阅 → 添加 → 添加订阅**，粘贴订阅链接并点击**添加**。也可以先复制链接，再点**粘贴**——BoxPilot
会识别剪贴板中的内容。分享链接、base64 列表、Clash / Clash.Meta YAML 和 sing-box JSON 都可以。

每张订阅卡片都可以停用、立即更新、编辑（更新间隔、启动时更新、User-Agent、包含 / 排除过滤）或删除。
点**选择**可以一次操作多个订阅。

### 单个节点（本地节点）

要添加单独得到的节点——`ss://`、`vmess://`、`vless://`、`trojan://`、`hysteria2://`、`hysteria://`、
`tuic://`、`anytls://`、`socks5://`、`http(s)://`、`wireguard://` 或 `ssh://`：

1. **订阅 → 添加 → 添加节点**（或复制链接后点**粘贴**）。
2. 粘贴一个或多个链接，每行一个，点击**添加**。

这些节点集中在**本地节点**卡片中，并在代理页作为独立的**本地节点**分组出现。每一行都有分享和删除按钮；
卡片上的开关可以整体启用或停用该分组。

### 分享节点

- 在**代理**页，把鼠标移到节点卡片上，点击名称旁的分享图标，分享链接就会复制到剪贴板。
- 在**订阅卡片**上，分享按钮会复制该订阅全部节点的链接。
- 在**本地节点**中，使用每行的分享按钮，或卡片上的复制按钮复制全部链接。

没有链接格式的节点（例如部分仅 sing-box 支持的类型）会被跳过，并在提示中计数。

## 4. 连接

**仪表盘 → 连接。** 状态卡片会显示当前模式、正在使用的节点以及流量的接入方式。

应用如何接入 BoxPilot（**仪表盘 → 快捷设置**）：

- **系统代理**——最简单的方式，浏览器和大多数应用都会遵循。在 macOS 上，BoxPilot 会为每个网络服务
  （Wi-Fi、以太网……）设置代理；如果 macOS 拒绝，会请求一次你的密码。
- **TUN 模式**——接管全部流量，包括不遵循系统代理的应用。Windows 需要以管理员身份运行 BoxPilot
  （它会提示以该方式重启）；macOS 首次会请求密码为内核授权；Linux 通过 `pkexec` 授权。在 macOS 上，
  TUN 开启期间系统 DNS 会指向它（由 BoxPilot 而不是路由器解析域名），关闭 TUN 后恢复你原来的 DNS 设置。
- 都不开启——应用仍可使用本地代理 `127.0.0.1:7890`（同一端口提供 HTTP 和 SOCKS5，可在
  **设置 → 代理**中修改）。

模式：**规则**按你的规则分流，**全局**让全部流量走代理，**直连**完全不走代理。切换即时生效。

## 5. 选择节点

**代理**页为每个分组提供一个标签。

- **节点选择**是总开关：自动选择、某个订阅分组或单个节点。
- **自动选择**替你挑选节点，可选方式：
  - **响应最快**——延迟最低，不会为微小差距频繁切换。
  - **稳定优先**——保留可用节点，只在失败或差距很大时切换。
  - **按列表顺序**——按列表顺序使用第一个可用节点，恢复后自动切回。
  - **带宽优先**——不时对最快的几个节点测速，保留速度最快的。

  还可以限定一个**地区**。两者修改后立即生效，无需重启内核。
- **测试延迟**、**真实延迟**和**测速**会测量当前显示的全部节点；点击卡片上的小数值只测该节点。
  节点也会按定时自动测试（**设置 → 高级 → 自动测试节点**）。

## 6. 规则

**规则**页决定规则模式下流量的去向。

- **添加规则集**：链接或本地文件——sing-box `.srs` / `.json`、Clash 规则提供者或 ACL4SSR `.list`
  文件。选择匹配流量的去向（代理、直连、拒绝或任意分组）。顺序很重要，可用箭头上下移动。
- **导入 ACL4SSR**：读取 subconverter `.ini`（一键选用 ACL4SSR_Online_Full），添加其中全部规则集，
  默认**处于关闭状态**。启用你需要的规则集，或使用列表上方的**全部启用** / **全部停用**。
- **独立节点组**：规则集下方的开关会让它的匹配流量在代理页拥有一个以规则集命名的独立分组（此时它的
  去向显示为**自定义**）。在该分组中选择**手动选择**后点击节点，或选择自动组的四种方式之一并可限定
  地区——例如让流媒体走某个国家的高速节点，其余流量仍用自动选择。
- **编辑文件**：带铅笔的文件按钮会用系统默认文本编辑器打开规则集文件。本地文件每次保存都会自动转换并
  生效；下载的规则集打开的是本地保存的副本，保存后立即生效，直到下次下载更新。二进制 `.srs` 文件无法
  以文本编辑。
- **内置规则**可绕过中国大陆并拦截广告；**自定义规则**按行填写，例如 `DOMAIN-SUFFIX,openai.com,proxy`。

## 7. 值得了解的设置

- **常规**：语言、主题、**主题色**、开机启动、关闭到托盘和**轻量模式**（关闭窗口即释放界面，代理在
  托盘中继续运行）。
- **图形**：**半透明窗口**、**材质**（Windows 11 上的 Mica、Mica Alt、Acrylic）和**透明度**。macOS 与
  KDE Plasma 使用系统模糊。
- **代理 / TUN / DNS**：端口、局域网访问、UDP 与 QUIC 处理、TUN 协议栈、DNS 服务器、FakeIP。
- **更新**：BoxPilot 如何处理新版本，以及**立即检查**。
- **高级 → 重置 BoxPilot**：清除设置、订阅、规则集或缓存。

## 8. 常见问题

- **连接后打不开网页**——打开**日志**查看。确认节点有响应（在代理页点**测试延迟**），并确认系统代理或
  TUN 已开启。
- **macOS 上出现“系统代理：……”错误**——在弹出的密码框中授权；如果没有弹出，请确认你的账户是管理员。
- **TUN 无法启动**——Windows 上以管理员身份重启 BoxPilot；macOS 上关闭再开启 TUN 以弹出密码授权。
- **规则集显示错误**——该行会说明原因；修正来源（或编辑过的文件）后点它的更新按钮。
- **从头开始**——**设置 → 高级 → 重置 BoxPilot**。

数据位置：`%APPDATA%\BoxPilot`（Windows）、`~/Library/Application Support/BoxPilot`（macOS）、
`$XDG_CONFIG_HOME/BoxPilot`（Linux）。
