## 1. Установка в вашей системе

Файлы лежат на странице [последнего релиза](https://github.com/BillBlueInnit/boxpilot/releases/latest).

### Windows

Windows 10 или 11, 64-битная.

1. Скачайте `BoxPilot-<версия>-windows-x64.zip` и распакуйте куда угодно, например в `C:\Apps\BoxPilot`.
2. Запустите `boxpilot.exe`. Если SmartScreen пишет «Система Windows защитила ваш компьютер», нажмите
   **Подробнее** → **Выполнить в любом случае** (приложение не подписано).

- **Переносной режим:** создайте папку `data` рядом с `boxpilot.exe` до первого запуска, и настройки будут
  храниться рядом с приложением, а не в `%APPDATA%\BoxPilot`.
- **Режиму TUN** нужны права администратора; BoxPilot предложит так перезапуститься. Чтобы всегда
  запускаться с правами, включите **Настройки → Общие → Запускать от администратора**: автозапуск тогда
  идёт через задачу планировщика, без запроса UAC.
- **Полупрозрачное окно:** Mica, Mica Alt или Acrylic в Windows 11 22H2 и новее.
- **Обновления:** BoxPilot обновляется сам (**Настройки → Обновления**).
- **Удаление:** выключите **Запускать при входе**, выйдите через трей, затем удалите папку приложения и
  `%APPDATA%\BoxPilot`.

### macOS

Mac на Apple silicon (M1 и новее) или Intel.

1. Скачайте `BoxPilot-<версия>-macos-arm64.dmg` (Apple silicon) или `-macos-x64.dmg` (Intel).
2. Откройте его и перетащите **BoxPilot** в **Программы**.

BoxPilot не нотаризован Apple, поэтому первый запуск требует ещё одного шага:

- Щёлкните BoxPilot в «Программах» правой кнопкой → **Открыть** → **Открыть**.
- В macOS 15 и новее: откройте приложение один раз, затем зайдите в **Системные настройки →
  Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
- Если macOS пишет, что приложение «повреждено», один раз выполните в Терминале и откройте его снова:

  ```bash
  xattr -dr com.apple.quarantine /Applications/BoxPilot.app
  ```

Дальше:

- **Системный прокси** задаётся для каждой сетевой службы (Wi-Fi, Ethernet…). Если macOS откажет, BoxPilot
  один раз запросит пароль.
- **Режим TUN** один раз запрашивает пароль для ядра и ещё раз после обновления ядра. Пока TUN включён,
  системный DNS указывает на него; ваши настройки DNS возвращаются, когда TUN выключается.
- **Обновления:** BoxPilot обновляется сам (**Настройки → Обновления**).
- **Удаление:** выключите **Запускать при входе**, выйдите, переместите BoxPilot в Корзину и удалите
  `~/Library/Application Support/BoxPilot`.

### Ubuntu, Debian, Linux Mint

Ubuntu 24.04, Debian 13, Linux Mint 22 или новее (64-битные).

```bash
sudo apt install ./boxpilot_<версия>-1_amd64.deb
```

BoxPilot появится в меню приложений.

- **Значок в трее:** в Ubuntu, KDE Plasma, Cinnamon и Xfce работает сразу. GNOME в Debian нужно расширение
  AppIndicator: `sudo apt install gnome-shell-extension-appindicator`, выйдите и снова войдите в систему и
  включите его в **Расширениях**.
- **Режим TUN** один раз запросит пароль (см. [Рабочие столы Linux](#права-для-tun)).
- **Обновления:** BoxPilot сообщит о новой версии; установите новый `.deb` так же.
- **Удаление:** `sudo apt remove boxpilot`. Ваши данные остаются в `~/.config/BoxPilot`.

### Fedora, openSUSE

Fedora 40 и новее или openSUSE Tumbleweed (64-битные).

```bash
sudo dnf install ./boxpilot-<версия>-1.x86_64.rpm      # Fedora
sudo zypper install ./boxpilot-<версия>-1.x86_64.rpm   # openSUSE
```

Если установщик предупредит, что пакет не подписан, согласитесь продолжить.

- **Значок в трее:** GNOME нужно расширение AppIndicator: `sudo dnf install gnome-shell-extension-appindicator`
  (openSUSE: `zypper install`), выйдите и снова войдите и включите его в **Расширениях**. В KDE Plasma
  работает сразу.
- **Режим TUN** один раз запросит пароль (см. [Рабочие столы Linux](#права-для-tun)).
- **Обновления:** BoxPilot сообщит о новой версии; установите новый `.rpm` так же.
- **Удаление:** `sudo dnf remove boxpilot` (openSUSE: `sudo zypper remove boxpilot`).

### Arch Linux, Manjaro, EndeavourOS

Каждый релиз BoxPilot одновременно служит репозиторием pacman. Добавьте его в `/etc/pacman.conf` один раз:

```ini
[boxpilot]
SigLevel = Optional TrustAll
Server = https://github.com/BillBlueInnit/boxpilot/releases/latest/download
```

То же одной командой, а затем установка:

```bash
printf '\n[boxpilot]\nSigLevel = Optional TrustAll\nServer = https://github.com/BillBlueInnit/boxpilot/releases/latest/download\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu boxpilot-bin
```

Подойдёт и `yay -Syu boxpilot-bin`. Пакеты не подписаны, поэтому запись доверяет тому, что отдают релизы
BoxPilot на GitHub.

- **Обновления** приходят с обычным `sudo pacman -Syu` (или `yay`).
- **Разовая установка** без репозитория (без обновлений):

  ```bash
  curl -LO https://github.com/BillBlueInnit/boxpilot/releases/latest/download/boxpilot-bin-x86_64.pkg.tar.zst
  sudo pacman -U ./boxpilot-bin-x86_64.pkg.tar.zst
  ```

- **Собрать самому:** в клоне этого репозитория `cd packaging/aur/boxpilot && makepkg -si`.
- **Трей, TUN, размытие:** см. [Рабочие столы Linux](#8-рабочие-столы-linux).
- **Удаление:** `sudo pacman -Rns boxpilot-bin`, затем удалите строки `[boxpilot]` из `/etc/pacman.conf`.

### NixOS

Пакета для Nix пока нет, и эти шаги не проверены — поправки приветствуются. Архив для Linux запускается
через [nix-ld](https://github.com/nix-community/nix-ld), который даёт ему привычные пути к библиотекам.
В `configuration.nix`:

```nix
programs.nix-ld = {
  enable = true;
  libraries = with pkgs; [
    stdenv.cc.cc.lib glib gtk3 gdk-pixbuf libxkbcommon xorg.libxcb xorg.libX11
    wayland vulkan-loader fontconfig freetype libayatana-appindicator
  ];
};
hardware.graphics.enable = true;               # драйверы Vulkan (до 24.11 — hardware.opengl)
environment.systemPackages = [ pkgs.libcap ];  # setcap, для режима TUN
```

После `sudo nixos-rebuild switch` распакуйте архив и запустите:

```bash
mkdir -p ~/BoxPilot && tar -xzf BoxPilot-<версия>-linux-x64.tar.gz -C ~/BoxPilot
~/BoxPilot/boxpilot
```

- **Режим TUN** запрашивает пароль через polkit или через собственное окно BoxPilot и `sudo`. Версии
  новее 1.0.3 находят `sudo` и `pkexec` из NixOS.
- **Обновления:** BoxPilot сам обновляет эту копию из архива (**Настройки → Обновления**).

### Другие дистрибутивы Linux

Любой 64-битный дистрибутив с glibc 2.39 или новее, GTK 3 и драйвером Vulkan. Для значка в трее нужна
ещё `libayatana-appindicator3`. Установка в домашнюю папку:

```bash
mkdir -p ~/.local/opt/boxpilot ~/.local/bin
tar -xzf BoxPilot-<версия>-linux-x64.tar.gz -C ~/.local/opt/boxpilot
ln -sf ~/.local/opt/boxpilot/boxpilot ~/.local/bin/boxpilot
cp -r ~/.local/opt/boxpilot/share/. ~/.local/share/     # пункт меню и значки
```

- **Обновления:** BoxPilot сам обновляет эту копию (**Настройки → Обновления**).
- **Удаление:** удалите `~/.local/opt/boxpilot`, `~/.local/bin/boxpilot`, файлы BoxPilot, скопированные в
  `~/.local/share` (`applications/boxpilot.desktop`, `icons/hicolor/*/apps/boxpilot.png`,
  `metainfo/io.github.billblueinnit.boxpilot.metainfo.xml`), и `~/.config/BoxPilot`.

## 2. Ядро sing-box

BoxPilot управляет ядром [sing-box](https://sing-box.sagernet.org), но не поставляет его. На странице
**Обзор** нажмите **Скачать ядро** (или **Настройки → Ядро sing-box → Скачать последнюю**), и BoxPilot
загрузит официальную сборку для вашей системы с GitHub.

Если GitHub у вас работает медленно, сначала укажите там же префикс **Зеркало GitHub**.

## 3. Добавление узлов

### Подписка

**Подписки → Добавить → Добавить подписку**, вставьте ссылку и нажмите **Добавить**. Или скопируйте ссылку
и нажмите **Вставить**: BoxPilot распознает содержимое буфера обмена. Подходят ссылки на узлы, списки в
base64, YAML Clash / Clash.Meta и JSON sing-box.

Каждую карточку подписки можно отключить, обновить сразу, изменить (интервал обновления, обновление при
запуске, User-Agent, фильтры включения / исключения) или удалить. **Выбрать** позволяет действовать над
несколькими сразу.

### Отдельные узлы

Для узла, полученного отдельно (`ss://`, `vmess://`, `vless://`, `trojan://`, `hysteria2://`,
`hysteria://`, `tuic://`, `anytls://`, `socks5://`, `http(s)://`, `wireguard://`, `ssh://`):

1. **Подписки → Добавить → Добавить узел** или скопируйте ссылку и нажмите **Вставить**.
2. Вставьте одну или несколько ссылок, по одной в строке, и нажмите **Добавить**.

Они собраны в карточке **Локальные узлы** и на странице прокси образуют группу **Локальные узлы**.
Переключатель на карточке включает или выключает всю группу.

### Поделиться узлом

| Где | Как |
| --- | --- |
| Страница «Прокси» | Наведите курсор на карточку узла и нажмите значок рядом с названием |
| Карточка подписки | Кнопка «поделиться» копирует ссылки всех её узлов |
| Локальные узлы | Кнопка в строке или кнопка копирования на карточке — для всех сразу |

Ссылка попадает в буфер обмена. Узлы без формата ссылки (некоторые типы только для sing-box) пропускаются,
их число указывается в сообщении.

## 4. Подключение

**Обзор → Подключить.** Карточка состояния показывает режим, используемый узел и то, как трафик попадает
в BoxPilot.

В **Обзор → Быстрые настройки** выберите, как приложения попадают в BoxPilot:

| Вариант | Что делает |
| --- | --- |
| **Системный прокси** | Самый простой. Ему следуют браузеры и большинство приложений. |
| **Режим TUN** | Перехватывает весь трафик, включая приложения, которые не смотрят на системный прокси. |
| Ни то ни другое | Приложения всё равно могут использовать локальный прокси `127.0.0.1:7890` (HTTP и SOCKS5 на одном порту, меняется в **Настройки → Прокси**). |

TUN требует разового разрешения:

| Система | Что происходит |
| --- | --- |
| Windows | BoxPilot перезапускается от имени администратора. |
| macOS | Один запрос пароля; ещё один после обновления ядра. |
| Linux | Один запрос пароля (polkit или собственное окно BoxPilot); ещё один после обновления ядра. |

В Linux системный прокси — это настройка GNOME и KDE. В оконных менеджерах без неё (niri, sway, Hyprland…)
многие приложения о нём не знают: используйте режим TUN или укажите приложению `127.0.0.1:7890`.

**Режимы:** **Правила** — по вашим правилам, **Глобальный** — всё через прокси, **Напрямую** — ничего через
прокси. Переключение мгновенное.

## 5. Выбор узлов

На странице **Прокси** у каждой группы своя вкладка.

- **Прокси** — главный переключатель: «Авто», группа подписки или отдельный узел.
- **Авто** выбирает узел за вас, при желании в пределах одного **региона**:

  | Способ | Выбирает |
  | --- | --- |
  | Быстрый отклик | Минимальная задержка, без скачков ради мелкого выигрыша |
  | Стабильность | Держит рабочий узел; меняет только при сбое или большой разнице |
  | По порядку списка | Первый рабочий узел по списку; возвращается к нему после восстановления |
  | Макс. скорость | Время от времени замеряет несколько самых быстрых и держит лучший |

  Изменения применяются сразу, без перезапуска ядра.
- **Проверить задержку**, **Реальная задержка** и **Тест скорости** измеряют все показанные узлы;
  маленькие значения на карточке проверяют только этот узел. Узлы также проверяются по таймеру
  (**Настройки → Дополнительно → Проверять узлы автоматически**).

## 6. Правила

Страница **Правила** определяет, куда идёт трафик в режиме «Правила».

- **Добавить набор:** ссылка или локальный файл: sing-box `.srs` / `.json`, провайдеры правил Clash или
  файлы ACL4SSR `.list`. Выберите, куда направлять совпадения (прокси, напрямую, блокировка или любая
  группа). Порядок важен: наборы перемещаются стрелками.
- **Импорт ACL4SSR:** читает `.ini` subconverter (ACL4SSR_Online_Full — в один клик) и добавляет все его
  наборы **выключенными**. Включите нужные или нажмите **Включить все** / **Отключить все**.
- **Своя группа узлов:** переключатель под набором даёт его совпадениям отдельную группу на странице прокси.
  В ней выберите **Вручную** и нажмите на узел или один из способов «Авто» с регионом по желанию. Например,
  стриминг через быстрый узел одной страны, а всё остальное — через «Авто».
- **Изменить файл:** кнопка с карандашом на листе открывает файл набора в текстовом редакторе. Локальный
  файл после каждого сохранения преобразуется и применяется. Для загруженного набора открывается
  сохранённая копия: изменения действуют сразу и до следующей загрузки. Двоичные `.srs` редактировать как
  текст нельзя.
- **Встроенные правила** обходят материковый Китай и блокируют рекламу. **Свои правила** — строки вида
  `DOMAIN-SUFFIX,openai.com,proxy`.

## 8. Рабочие столы Linux

### Значок в трее

Значок BoxPilot в трее — это элемент AppIndicator (StatusNotifier).

| Рабочий стол | Что нужно |
| --- | --- |
| Ubuntu, KDE Plasma, Cinnamon, Xfce | Ничего |
| GNOME в других дистрибутивах (Fedora, Debian, Arch…) | Расширение AppIndicator (`gnome-shell-extension-appindicator`) |
| niri, sway, Hyprland и другие оконные менеджеры | Панель с треем, например Waybar |

Пакеты ставят библиотеку AppIndicator сами. Архиву нужна `libayatana-appindicator3`.

### Права для TUN

Для режима TUN ядру нужна возможность `CAP_NET_ADMIN`. В первый раз BoxPilot запрашивает пароль через
polkit и выдаёт её через `setcap` (или, если `setcap` не установлен, делает ядро setuid root). После
обновления ядра запрос повторяется.

В оконных менеджерах часто не запущен агент polkit, который показал бы этот запрос. Тогда BoxPilot
показывает собственное окно **Нужны права администратора**: введите пароль и нажмите **Разрешить** — он один
раз передаётся `sudo` и нигде не сохраняется. В окне есть и та же команда, чтобы выполнить её в терминале.

### Полупрозрачное окно и размытие

BoxPilot делает окно полупрозрачным только там, где композитор умеет размывать фон за ним:

| Композитор | Полупрозрачное размытое окно |
| --- | --- |
| KDE Plasma (Wayland) | Да |
| niri | Да |
| Другие композиторы Wayland | Да, если они предлагают `ext-background-effect` или размытие KDE |
| GNOME, sway, любой сеанс X11 | Нет, окно непрозрачное |

Строка `compositor blur:` в `boxpilot.log` показывает, что нашёл BoxPilot.

### Тайлинговые композиторы

В niri, sway, Hyprland, river и i3 рамку и тень окна рисует композитор, и BoxPilot оставляет это ему.
`BOXPILOT_DECORATIONS=client` (рамка BoxPilot) или `server` (рамка композитора) меняет этот выбор.

В niri это правило окна в `~/.config/niri/config.kdl` убирает рамку и тень niri вокруг BoxPilot и заставляет
размытие показывать окна позади него, а не только обои («xray» в niri):

```kdl
window-rule {
    match app-id="^BoxPilot$"
    shadow { off; }
    border { off; }
    draw-border-with-background false
    background-effect {
        xray false
    }
}
```

### Ноутбуки с двумя GPU

Если у GPU, который выводит изображение на экран (обычно Intel или AMD), нет драйвера Vulkan, BoxPilot
рисуется на другом GPU и каждый кадр копируется между ними — прокрутка подтормаживает. Установите драйвер:

| Система | Пакет |
| --- | --- |
| Arch | `vulkan-intel` (Intel) или `vulkan-radeon` (AMD) |
| Debian, Ubuntu, Fedora | `mesa-vulkan-drivers` |

**Настройки → Графика → Аппаратное ускорение** предупреждает об этом, а `boxpilot.log` называет
используемый GPU (`Selected GPU`).

## 9. Если что-то не так

- **После подключения ничего не открывается:** откройте **Журнал**. Убедитесь, что узел отвечает
  (**Проверить задержку** на странице прокси) и что включён системный прокси или TUN.
- **Системный прокси не действует в Linux:** см. примечание в разделе [Подключение](#4-подключение);
  используйте режим TUN.
- **macOS: ошибка «Системный прокси: …»:** подтвердите запрос пароля. Если запроса не было, проверьте, что
  ваша учётная запись — администратор.
- **TUN не запускается:**
  - Windows: перезапустите BoxPilot от имени администратора.
  - macOS: выключите и снова включите TUN, чтобы появился запрос пароля.
  - Linux: выключите и снова включите TUN и введите пароль в запросе polkit или в окне BoxPilot. Ошибка
    «mounted nosuid» значит, что файловая система домашней папки не допускает такое разрешение.
- **Нет значка в трее в Linux:** см. [Значок в трее](#значок-в-трее).
- **На ноутбуке подтормаживает прокрутка:** см. [Ноутбуки с двумя GPU](#ноутбуки-с-двумя-gpu).
- **Набор правил показывает ошибку:** в строке указана причина. Исправьте источник (или
  отредактированный файл) и нажмите кнопку обновления набора.
- **Начать заново:** **Настройки → Дополнительно → Сбросить BoxPilot**.

## 10. Где хранятся данные

| Система | Настройки, подписки, ядро, журнал | Автозапуск |
| --- | --- | --- |
| Windows | `%APPDATA%\BoxPilot` или `data` рядом с `boxpilot.exe` | Ключ Run или задача планировщика `BoxPilot` |
| macOS | `~/Library/Application Support/BoxPilot` | `~/Library/LaunchAgents/app.boxpilot.BoxPilot.plist` |
| Linux | `~/.config/BoxPilot` (`$XDG_CONFIG_HOME/BoxPilot`) | `~/.config/autostart/boxpilot.desktop` |

Журнал — файл `boxpilot.log` в папке данных; кнопка с папкой на странице **Журнал** открывает её.
