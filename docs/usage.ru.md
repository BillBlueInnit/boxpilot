# Как пользоваться BoxPilot

[English](usage.md) · [简体中文](usage.zh-CN.md) · **Русский** · [Назад к README](../README.ru.md)

Эта инструкция проведёт от установки BoxPilot до маршрутизации приложений через ваши узлы так, как вам
нужно.

## 1. Установка

Скачайте файл для своей системы на странице [Releases](https://github.com/BillBlueInnit/boxpilot/releases).

| Система | Файл | Как |
| --- | --- | --- |
| Windows 10/11 | `BoxPilot-<версия>-windows-x64.zip` | Распакуйте куда угодно и запустите `boxpilot.exe`. |
| macOS, Apple silicon | `BoxPilot-<версия>-macos-arm64.dmg` | Откройте .dmg и перетащите **BoxPilot** в **Applications** («Программы»). |
| macOS, Intel | `BoxPilot-<версия>-macos-x64.dmg` | Так же. |
| Linux x64 | `BoxPilot-<версия>-linux-x64.tar.gz` | Распакуйте и запустите `./boxpilot`. |

**macOS, первый запуск.** BoxPilot не нотаризован Apple, поэтому при первом открытии macOS спросит
разрешения. Щёлкните BoxPilot в «Программах» правой кнопкой → **Открыть** → **Открыть**. В macOS 15 и
новее: откройте приложение один раз, затем зайдите в **Системные настройки → Конфиденциальность и
безопасность** и нажмите **Всё равно открыть**. Если macOS пишет, что приложение «повреждено», один раз
выполните в Терминале команду ниже и откройте его снова:

```bash
xattr -dr com.apple.quarantine /Applications/BoxPilot.app
```

**Linux.** Для значка в трее нужен трей с поддержкой AppIndicator (в GNOME — расширение AppIndicator).

BoxPilot обновляется сам: в **Настройки → Обновления** выберите, устанавливать новые версии
автоматически, только напоминать или не сообщать вовсе.

## 2. Ядро sing-box

BoxPilot управляет ядром [sing-box](https://sing-box.sagernet.org), но не поставляет его. На странице
**Обзор** нажмите **Скачать ядро** (или **Настройки → Ядро sing-box → Скачать последнюю версию**).
BoxPilot загрузит официальную сборку для вашей системы с GitHub. Если GitHub у вас работает медленно,
сначала укажите там же префикс **Зеркало GitHub**.

## 3. Добавление узлов

### Подписка от провайдера

**Подписки → Добавить → Добавить подписку**, вставьте ссылку на подписку и нажмите **Добавить**. Или
скопируйте ссылку и нажмите **Вставить** — BoxPilot распознает содержимое буфера обмена. Подходят ссылки
на узлы, списки в base64, YAML Clash / Clash.Meta и JSON sing-box.

Каждую карточку подписки можно отключить, обновить сразу, изменить (интервал обновления, обновление при
запуске, User-Agent, фильтры включения / исключения) или удалить. **Выбрать** позволяет действовать над
несколькими сразу.

### Отдельные узлы (локальные узлы)

Чтобы добавить узел, полученный отдельно, — `ss://`, `vmess://`, `vless://`, `trojan://`, `hysteria2://`,
`hysteria://`, `tuic://`, `anytls://`, `socks5://`, `http(s)://`, `wireguard://` или `ssh://`:

1. **Подписки → Добавить → Добавить узел** (или скопируйте ссылку и нажмите **Вставить**).
2. Вставьте одну или несколько ссылок, по одной в строке, и нажмите **Добавить**.

Они собраны в карточке **Локальные узлы** и на странице прокси образуют отдельную группу **Локальные
узлы**. В каждой строке есть кнопки «поделиться» и «удалить»; переключатель на карточке включает или
выключает всю группу.

### Поделиться узлом

- На странице **Прокси** наведите курсор на карточку узла и нажмите значок рядом с названием — ссылка
  скопируется в буфер обмена.
- На **карточке подписки** кнопка «поделиться» копирует ссылки всех её узлов.
- В **Локальных узлах** используйте кнопку в строке или кнопку копирования на карточке для всех сразу.

Узлы без формата ссылки (например, некоторые типы только для sing-box) пропускаются, их число
указывается в сообщении.

## 4. Подключение

**Обзор → Подключить.** Карточка состояния показывает режим, используемый узел и то, как трафик попадает
в BoxPilot.

Как приложения попадают в BoxPilot (**Обзор → Быстрые настройки**):

- **Системный прокси** — самый простой вариант. Ему следуют браузеры и большинство приложений. В macOS
  BoxPilot задаёт его для каждой сетевой службы (Wi-Fi, Ethernet…); если macOS откажет, приложение один
  раз запросит пароль.
- **Режим TUN** — перехватывает весь трафик, включая приложения, которые не смотрят на системный прокси.
  В Windows BoxPilot должен работать от имени администратора (он предложит так перезапуститься); macOS
  один раз запросит пароль для ядра; Linux спросит через `pkexec`.
- Ни то ни другое — приложения всё равно могут использовать локальный прокси `127.0.0.1:7890` (HTTP и
  SOCKS5 на одном порту; изменить можно в **Настройки → Прокси**).

Режимы: **Правила** — по вашим правилам, **Глобальный** — всё через прокси, **Напрямую** — ничего через
прокси. Переключение мгновенное.

## 5. Выбор узлов

На странице **Прокси** у каждой группы своя вкладка.

- **Прокси** — главный переключатель: «Авто», группа подписки или отдельный узел.
- **Авто** выбирает узел за вас. Способы:
  - **Быстрый отклик** — минимальная задержка, без скачков ради мелкого выигрыша.
  - **Стабильность** — держит рабочий узел и меняет его только при сбое или большой разнице.
  - **По порядку списка** — первый рабочий узел по списку; возвращается к нему после восстановления.
  - **Макс. скорость** — время от времени замеряет скорость нескольких самых быстрых и держит лучший.

  Можно также ограничить выбор одним **регионом**. Изменения применяются сразу, без перезапуска ядра.
- **Проверить задержку**, **Реальная задержка** и **Тест скорости** измеряют все показанные узлы;
  маленькие значения на карточке проверяют только этот узел. Узлы также проверяются автоматически по
  таймеру (**Настройки → Дополнительно → Проверять узлы автоматически**).

## 6. Правила

Страница **Правила** определяет, куда идёт трафик в режиме «Правила».

- **Добавить набор**: ссылка или локальный файл — sing-box `.srs` / `.json`, провайдеры правил Clash или
  файлы ACL4SSR `.list`. Выберите, куда направлять совпадения (прокси, напрямую, блокировка или любая
  группа). Порядок важен: перемещайте наборы стрелками.
- **Импорт ACL4SSR**: читает `.ini` subconverter (ACL4SSR_Online_Full — в один клик) и добавляет все
  его наборы **выключенными**. Включите нужные или воспользуйтесь кнопками **Включить все** /
  **Отключить все** над списком.
- **Своя группа узлов**: переключатель под набором правил даёт его совпадениям отдельную группу на
  странице прокси с именем набора (цель тогда показывается как **Своя группа**). В этой группе выберите
  **Вручную** и нажмите на узел или один из четырёх способов «Авто» с регионом по желанию — например,
  стриминг через быстрый узел одной страны, а всё остальное — через «Авто».
- **Изменить файл**: кнопка с карандашом на листе открывает файл набора в текстовом редакторе по
  умолчанию. Локальный файл после каждого сохранения автоматически преобразуется и применяется. Для
  загруженного набора открывается сохранённая копия: изменения действуют сразу и до следующей загрузки.
  Двоичные файлы `.srs` редактировать как текст нельзя.
- **Встроенные правила** обходят материковый Китай и блокируют рекламу; **Свои правила** — строки вида
  `DOMAIN-SUFFIX,openai.com,proxy`.

## 7. Полезные настройки

- **Общие**: язык, тема, **Цвет темы**, автозапуск, закрытие в трей и **Облегчённый режим** (закрытие
  окна освобождает интерфейс, прокси продолжает работать в трее).
- **Графика**: **Полупрозрачное окно**, **Материал** (Mica, Mica Alt, Acrylic в Windows 11) и
  **Прозрачность**. В macOS и KDE Plasma используется системное размытие.
- **Прокси / TUN / DNS**: порты, доступ из локальной сети, обработка UDP и QUIC, стек TUN, DNS-серверы,
  FakeIP.
- **Обновления**: как BoxPilot обращается с новыми версиями, и **Проверить**.
- **Дополнительно → Сбросить BoxPilot**: очистить настройки, подписки, наборы правил или кэши.

## 8. Если что-то не так

- **После подключения ничего не открывается** — откройте **Журнал**. Убедитесь, что узел отвечает
  (**Проверить задержку** на странице прокси) и что включён системный прокси или TUN.
- **macOS: ошибка «Системный прокси: …»** — подтвердите запрос пароля; если запроса не было,
  проверьте, что ваша учётная запись — администратор.
- **TUN не запускается** — в Windows перезапустите BoxPilot от имени администратора; в macOS выключите и
  снова включите TUN, чтобы появился запрос пароля.
- **Набор правил показывает ошибку** — в строке указана причина; исправьте источник (или
  отредактированный файл) и нажмите кнопку обновления набора.
- **Начать заново** — **Настройки → Дополнительно → Сбросить BoxPilot**.

Где хранятся данные: `%APPDATA%\BoxPilot` (Windows), `~/Library/Application Support/BoxPilot` (macOS),
`$XDG_CONFIG_HOME/BoxPilot` (Linux).
